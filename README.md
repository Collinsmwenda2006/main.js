# iyf-s12-week-04-Collinsmwenda2006

Week 4: JavaScript Fundamentals. Practice tasks from Lessons 7 and 8, plus two mini-projects: an interactive calculator and a student grade tracker.

**Author:** Collins Mwenda (GitHub: [Collinsmwenda2006](https://github.com/Collinsmwenda2006))

## How to run

1. Open the folder in VS Code and start **Live Server** on `index.html`.
2. Press `F12` and open the **Console** to see the output of every task.
3. Use the calculator form on the page for the interactive version.

## What is inside

| File | Contents |
| --- | --- |
| `index.html` | Page that loads all scripts and hosts the calculator form |
| `main.js` | Tasks 7.1-7.4 and 8.1-8.4: variables, operators, functions, control flow, arrays, objects, array of objects, JSON |
| `calculator.js` | Calculator mini-project: `add`, `subtract`, `multiply`, `divide`, `calculate(num1, operator, num2)` with `+ - * / % **` and division-by-zero handling |
| `gradeTracker.js` | Student grade tracker mini-project: `addStudent`, `getStudent`, `getStudentAverage`, `getSubjectAverage`, `getTopStudent`, `getStrugglingStudents`, `getLetterGrade`, `generateReportCard` |
| `challenges.js` | Daily challenges: FizzBuzz, reverse a string, largest number, remove duplicates, palindrome checker |
| `ui.js` | Wires the calculator form to `calculate()` |
